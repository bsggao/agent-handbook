## 活动名称：使用 LangGraph 和 Azure Cosmos DB 构建多 Agent API

## 描述

多 Agent AI 应用的兴起正在改变我们构建智能系统的方式——但是如何为真实世界的可扩展性和性能设计架构？在本场会议中，我们将深入剖析使用 LangGraph 做 Agent 编排、FastAPI 作为 API 层、Azure Cosmos DB 作为状态管理、向量存储和事务数据支撑的生产级多 Agent 应用。

通过详细代码讲解，你将了解如何设计和实现一个结合检索增强生成（RAG）、记忆持久化和动态状态转换的 Agent 驱动工作流。内容涵盖:

使用 LangGraph 进行结构化推理的 Agent 协作
使用 Azure Cosmos DB 实时存储聊天记录——同一数据库为历史上增长最快的 AI Agent 应用 ChatGPT 提供支持
利用 Cosmos DB 原生嵌入支持的向量搜索实现知识检索
FastAPI 的异步能力保持响应快速且具备可扩展性
本场会议结束时，你将拥有构建与部署现代 AI 和云基础设施驱动的可扩展云原生多 Agent 应用的清晰蓝图。无论你是 AI 工程师、云架构师还是 Python 开发者，本讲座都将提供实用见解和经过检验的模式，助你打造下一代 AI 驱动应用。

## 活动名称：提示即新脚本：认识 GenAIScript

## 描述

jQuery 曾通过抽象复杂性，让 Web 开发更简单，使开发者能专注构建无需为浏览器差异烦恼。如今，AI 开发面临类似挑战。新模式层出不穷，跟进难度加大，尤其当 AI 工具——特别是 Agent 型工具——变得更强大且复杂。假如你能利用前沿 AI 能力，通过简单熟悉的 JavaScript 抽象来自动化任务？这就是 GenAIScript——一种将 AI 无缝融入工作流的方式，将提示视作可复用代码片段。本讲座将探讨 GenAIScript 如何使 AI 自动化 Agent 变得如写 JavaScript 般直观，助你简化重复工作，无需深厚 AI 专业。
