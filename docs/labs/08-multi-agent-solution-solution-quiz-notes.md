# 知识检测答案

## 问题1

 **答案：A2。** 当任务具有明确的专业角色、不同的工具或权限，以及需要协调的清晰交接时，多 Agent 是有用的。一个简单的支持机器人通常可以保持为单一 Agent。大量相同请求主要是一个扩展问题，本身并不需要多 Agent 设计。

## 问题2

 **答案：A1。** 当一套说明和工具能够处理任务时，单一 Agent 通常更易于测试、观察和操作。访问多个工具并不自动要求多个 Agent。不同权限和审计要求的不同角色可能证明多 Agent 设计是合理的。
