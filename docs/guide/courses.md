# 课程总览

19 章从准备环境到安全与部署，按原仓库编号映射。正文保留原课程知识点，穿插“补充讲解”和“扩展实践”；每章底部可以进入完整 Notebook 与脚本导读。

没有云账号也能阅读全部内容、搜索、操作三个模拟实验，并运行本地综合项目。学习时长为本项目的粗略阅读与基础练习估计，外部账号配置不计入。

## 从这里开始

- [00 · 环境配置与学习准备](/lessons/setup.md)：准备 Python、运行环境与第一个实验。 约 35 分钟。
- [01 · AI Agent 入门与应用场景](/lessons/introduction.md)：从一个旅行助手理解 Agent 的工作方式。 约 40 分钟。
- [02 · 探索 Agent 框架](/lessons/frameworks.md)：理解框架负责什么，以及如何选择。 约 45 分钟。

## 核心设计模式

- [03 · Agent 设计模式](/lessons/design-patterns.md)：将目标、行动、反馈组织成可靠的系统。 约 40 分钟。
- [04 · 工具调用](/lessons/tools.md)：让模型提出请求，让应用安全地执行。 约 55 分钟。
- [05 · Agentic RAG](/lessons/rag.md)：从文档中找证据，给回答附上出处。 约 60 分钟。
- [06 · 构建可信赖的 Agent](/lessons/trust.md)：设置边界，把人纳入关键决策。 约 45 分钟。
- [07 · 规划模式](/lessons/planning.md)：拆解任务、跟踪依赖，并根据结果调整。 约 50 分钟。
- [08 · 多 Agent 协作](/lessons/multi-agent.md)：用清晰的角色、交接和汇总协作。 约 65 分钟。
- [09 · 元认知与反思](/lessons/reflection.md)：检查可观察的结果，改进下一次行动。 约 45 分钟。

## 走向真实应用

- [10 · Agent 生产实践](/lessons/production.md)：从一次跑通走向可观测、可评估的服务。 约 60 分钟。
- [11 · Agent 协议：MCP、A2A、NLWeb](/lessons/protocols.md)：连接工具、其他 Agent 与网站知识。 约 65 分钟。
- [12 · 上下文工程](/lessons/context.md)：为每次模型调用选取合适的信息。 约 45 分钟。
- [13 · Agent 记忆](/lessons/memory.md)：让信息跨会话延续，同时保持可控。 约 50 分钟。

## 进阶工程实践

- [14 · Microsoft Agent Framework](/lessons/agent-framework.md)：用工作流、交接与中间件组织应用。 约 70 分钟。
- [15 · Computer Use 与 Browser Use](/lessons/browser-use.md)：理解观察、操作、验证的界面自动化循环。 约 50 分钟。
- [16 · 可扩展部署](/lessons/deployment.md)：处理并发、成本、故障和服务边界。 约 65 分钟。
- [17 · 本地 Agent](/lessons/local-agents.md)：在本地运行模型、检索与工具。 约 55 分钟。
- [18 · Agent 安全](/lessons/security.md)：验证授权与执行记录，防止越权和篡改。 约 60 分钟。

## 如何使用本指南

第一次学习从[学习路线](./roadmap.md)开始。需要查术语时使用[术语表](./glossary.md)；运行失败时先按[排错指南](./faq.md)缩小范围。每章“标记完成”只保存在当前浏览器，不会上传。数据清理、隐私模式或更换设备后不会自动同步。
